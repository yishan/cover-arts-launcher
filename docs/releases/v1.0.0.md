# Cover Arts Launcher v1.0.0

The first public release provides a three-position Cover Art play library for
FoloToy AI Passport and a browser-based manager for complete installation and
play management.

## Highlights

- Three fixed play positions with cover-first on-device navigation.
- Generic compatible firmware installation without a Launcher SDK.
- Verified app, cover, metadata, and trust-receipt writes with scoped erasure and
  recovery behavior.
- Official Play URL import plus local firmware import.
- Chinese title support with pre-install glyph checks.
- Local cover preview, crop, compression, and RGB565 conversion.
- Reset or power-cycle returns to the Launcher; optional cover-page `Up Long`
  integration is available to creators.

## Release files

- Raw complete 8 MiB image for writing at `0x0`.
- ZIP-compressed copy of the same image.
- SHA-256 checksum list.
- Third-party notices.

Complete installation replaces the existing Flash layout and installed play
positions. Read the
[installation guide](https://github.com/yishan/cover-arts-launcher/blob/v1.0.0/docs/installation.md)
before flashing.
