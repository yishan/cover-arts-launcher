# Cover Arts Launcher v1.0.0

首个公开版本为 FoloToy AI Passport 提供三个位置的 Cover Art 玩法库，以及用于完整安装和玩法管理的
浏览器工具。

## 主要能力

- 三个固定玩法位置，以封面为主的设备端浏览界面。
- 通用兼容固件无需 Launcher SDK 即可安装。
- 对 App、封面、元数据和信任记录执行验证写入，并提供限定范围的擦除和故障恢复。
- 支持导入官方 Play URL 或本地固件。
- 支持中文标题，并在安装前检查字形。
- 在浏览器本地完成封面预览、裁切、压缩和 RGB565 转换。
- 重启或重新上电返回 Launcher；创作者可选择在玩法封面页接入 `Up Long` 返回。

## Release 文件

- 从 `0x0` 写入的原始完整 8 MiB 固件。
- 同一固件的 ZIP 压缩包。
- SHA-256 校验清单。
- 第三方声明。

完整安装会替换现有 Flash 布局和已安装玩法。写入前请阅读
[安装指南](https://github.com/yishan/cover-arts-launcher/blob/v1.0.0/docs/installation.zh_CN.md)。
