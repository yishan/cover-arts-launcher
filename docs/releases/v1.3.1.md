# Cover Arts Launcher v1.3.1

v1.3.1 replaces the fixed three-position layout with dynamic play storage and
improves the on-device library and details experience.

## Highlights

- Allocates space from each verified firmware image's actual size, then appends
  plays while enough contiguous Flash space remains.
- Shows only installed covers; one play shows one cover and two plays show two.
- Adds a compact details view with version, first install time, latest
  install/update time, and launch count.
- Improves Chinese labels and play-title support, cover layout, bottom hints,
  metadata recognition, and launch-time verification.
- Keeps generic play compatibility: installation and launch require no Launcher
  SDK. Restart or power cycle returns to the library; adapted cover pages may
  optionally support `Up Long`.

## Migration notice

The first complete installation of v1.3.1 changes the Launcher Flash layout and
clears plays installed under an older fixed-position version. Add those plays
again through the Play Manager after migration.

v1.3.1 is append-only. It does not yet include arbitrary middle deletion or
automatic physical compaction.

## Release file

`FoloToy-AI-Passport-Cover-Arts-Launcher-v1.3.1-full.bin` is the complete 8 MiB
image for writing at `0x0`. Verify it with `SHA256SUMS.txt` before installation.
