# Cover Arts Launcher v1.5.0

v1.5.0 makes the dynamic play library easier to maintain and more reliable for
back-to-back installs.

## Highlights

- Removes any installed play, then closes the visible gap by reassigning the
  remaining plays' logical positions without copying their application bytes.
- Reuses the smallest released Flash range that fits a later play before
  consuming free space at the end of the library.
- Preserves launch counts across logical reordering by following each play's
  stable Source ID or firmware identity.
- Keeps one browser permission session for consecutive installs, refreshes the
  download session between plays, and restarts the device only when the user
  finishes managing the library.
- Improves Web Serial reliability with serialized reads and writes, a stable
  transfer rate, clearer recovery messages, and verified directory readback.
- Retains the v1.3.1 dynamic-storage format, installed covers, and generic-play
  compatibility. Physical compaction of fragmented free space is not included.

## Upgrade notice

Devices already running v1.3.1 use the same dynamic-storage layout. Install the
v1.5.0 complete image to update the Launcher, then reconnect the Play Manager.
As with any complete-system write, export data that must be retained before
installation and recheck the play library afterwards.

## Release file

`FoloToy-AI-Passport-Cover-Arts-Launcher-v1.5.0-full.bin` is the complete 8 MiB
image for writing at `0x0`. Verify it with `SHA256SUMS.txt` before installation.
