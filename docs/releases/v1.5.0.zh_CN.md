# Cover Arts Launcher v1.5.0

v1.5.0 重点改进动态玩法库维护和连续安装体验。

## 更新内容

- 支持删除任意已安装玩法；删除后自动补齐界面中的逻辑位置，不复制保留玩法的 App 数据。
- 后续安装会优先复用能够容纳玩法的最小已释放空间，再使用玩法库尾部空间。
- 以稳定 Source ID 或固件身份保存启动次数，逻辑位置重排后仍可延续计数。
- 一次连接可连续安装多个玩法；管理器会在每款玩法完成后自动刷新下载会话，用户完成管理时
  再统一重启设备。
- 优化 Web Serial 稳定性：串行化读写、采用稳定传输速率、完善恢复提示，并在提交后重新读取
  玩法目录进行校验。
- 延续 v1.3.1 动态存储格式、已有封面和通用玩法兼容策略；本版本不包含碎片空间的物理整理。

## 升级提醒

已经运行 v1.3.1 的设备使用相同的动态存储布局。安装 v1.5.0 完整固件更新 Launcher 后，
重新连接玩法管理器即可。完整系统写入前，请先导出必须保留的数据，并在完成后重新检查玩法库。

## 发布文件

`FoloToy-AI-Passport-Cover-Arts-Launcher-v1.5.0-full.bin` 是从 `0x0` 写入的完整
8 MiB 固件。安装前请使用 `SHA256SUMS.txt` 校验文件。
