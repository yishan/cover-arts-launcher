# Cover Arts Launcher v1.6.0

v1.6.0 reduces Launcher storage overhead and improves verified play installation.

[Simplified Chinese release notes](https://github.com/yishan/cover-arts-launcher/blob/v1.6.0/docs/releases/v1.6.0.zh_CN.md).

## Highlights

- Adds a compact Factory partition. The play area grows by **512 KiB**, from
  6.4375 MiB to **6.9375 MiB** on an 8 MiB AI Passport.
- Reduces application size through lossless Chinese-font compression,
  size-oriented compilation, and removal of unused LVGL widgets. Chinese title
  coverage and the Cover Art interface remain unchanged.
- Updates the Play Manager to recognize both the older dynamic layout and the
  v1.6.0 compact layout. Ordinary play management follows the device's actual
  partition table; it does not silently migrate the layout.
- Accelerates full App readback at 230400 baud, then restores 115200 baud before
  subsequent writes. Complete App verification and directory-last commit remain
  enabled. The same Play #702 took 108.493 s before and 54.237 s after this change
  in local device tests; these are readback-phase timings, not total-install or
  universal performance claims.
- Preserves consecutive installation in one connection, arbitrary deletion,
  logical reordering, released-space reuse, and generic-play compatibility.
  Automatic physical compaction is not included.

## Upgrade notice

**Use complete Launcher initialization to adopt the compact layout. This clears
installed plays and covers. Download the original play files and save any data
you need before starting; reinstall the plays afterwards.** A raw full-image
write at `0x0` can also reset NVS settings and saved counters. Updating the online
manager alone does not release the additional space. Do not replace only the
partition table or assume an App-only update migrates existing play data.

Use the hosted [Play Manager](https://calm.yishan.app/) and follow the
[installation guide](../installation.md). Third-party play-save export and
restoration are not guaranteed.

## Release files and validation

`FoloToy-AI-Passport-Cover-Arts-Launcher-v1.6.0-full.bin` is a complete
**8,388,608-byte** image for `0x0`. Empty Flash padding keeps the raw file at
8 MiB; the ZIP is smaller, but must be extracted before installation. Verify
the downloaded files against the Release's `SHA256SUMS.txt`.

- Build: local ESP-IDF 5.5.3 gate passed; the Release workflow builds the
  published image independently.
- Host tests: local static, C/Python, and 195 browser-module tests passed before
  release preparation; the final source is checked again before tagging.
- Device tests: the local compact-layout development build and consecutive play
  installation were accepted, with normal covers and play launch. The exact
  CI-produced Release image has not been flashed in this release task.
- Unverified: exact Release-image device acceptance, broad USB/browser coverage,
  and third-party save-data migration.

Source and license acknowledgements, including meta-pass, remain in the paired
third-party notices shipped with the Release.
