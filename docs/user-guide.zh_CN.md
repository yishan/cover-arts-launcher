# Cover Arts Launcher 用户指南

## 设备按键

- `Up` / `Down`：在已安装玩法之间移动。
- `OK`：启动居中的玩法。
- 长按 `OK`：打开详情；在详情页按 `OK` 返回玩法库。
- 重启或重新上电：返回 Launcher，同时保留已校验的玩法。
- 仅限已适配玩法：在该玩法已有封面页或开始页长按 `Up`，直接返回 Launcher。
  该快捷操作不是安装要求，也不应影响游戏过程。

玩法库只显示实际已安装玩法。底部位置指示表示“当前玩法 / 已安装总数”，不会预先填充空位置。

## 玩法详情

详情页显示版本、首次安装时间、最近一次安装／更新时间和启动次数。旧版元数据在玩法通过
动态 Launcher 再次安装或更新前，部分字段可能显示“暂无记录”。

## 安装玩法

线上玩法管理器接受官方 Play 详情 URL 或本地 `.bin`。写入前请核对识别到的标题、版本、
Source ID、固件哈希和封面。管理器会校验 ESP32-C3 App，并检查中文标题字形覆盖。

v1.6.0 按已校验 App 的实际长度加 Sidecar 分配空间，优先复用能够容纳玩法的最小释放范围，
再使用玩法库尾部空间。
OTA 玩法条目的理论上限为 16 个，但实际通常先受可用 Flash 空间限制。

可以连续安装多个玩法而无需重新选择串口。每款完成后选择继续，管理器会保留浏览器授权并刷新
下载会话；全部安装结束后，再完成会话并统一重启设备。

安装后请区分两个状态：

1. 浏览器完成 Flash 校验并发送了复位请求。
2. 用户在设备上看到了新封面，并成功启动玩法。

只有第二项属于真机确认。

## 删除玩法

在维护区域选择任意已安装玩法，核对名称和身份后确认删除。其余封面会自动补齐逻辑位置，
但玩法 App 数据不会被搬动；后续安装可复用释放的空间。

如果总空闲容量足够，但所有空闲范围都小于新玩法所需连续空间，管理器会在擦除前停止并提示。
v1.6.0 不包含自动物理整理。

## 通用玩法和可选返回支持

兼容的通用玩法无需修改源码即可安装和启动。如果玩法没有接入可选返回协议，用户重启或重新上电
即可返回 Launcher。创作者可以使用[兼容 Skill](../skills/ai-passport-cover-arts-launcher/SKILL.zh_CN.md)，
仅在玩法已有封面页或开始页接入 `Up Long`。

## 常见恢复操作

- **浏览器断开：** 重新连接并扫描后再判断安装状态，不要依赖已经过期的网页提示。
- **玩法写入失败：** 仅在管理器确认未完成 App 不可启动后重试；如果中断发生在动态分区表提交阶段，
  使用完整系统安装恢复。
- **网页提示已发送复位，但显示未变化：** 重新连接、重新扫描，再手动重启设备。
- **标题或封面不正确：** 先重新扫描。Launcher 只接受与已安装 App 身份一致且通过完整性校验的元数据。
