通用兼容

无需 Launcher SDK。玩法正常启动和运行；复位或重新上电后返回 Launcher，原有名称和封面继续保留。

可选增强

封面快捷返回

只在玩法自己已有的封面／开始页处理 Up Long。游戏、设置、暂停和其他页面的按键行为保持不变。

边界比按键更重要

如果 Agent 无法可靠识别封面状态，就应停止并说明情况；不能新增全局监听，也不能为了协议擅自创建封面页。设备重启返回 Launcher 始终是通用兜底。

交给 Agent 接入

将下面的指令发送给支持 Skill 的 Agent：

请使用 $ai-passport-cover-arts-launcher，仅在当前玩法已有的封面页接入长按 Up 返回 Cover Arts Launcher。不要全局占用 Up Long，不要修改游戏、设置或其他页面的按键行为；如果项目没有可识别的封面状态，先说明情况，不要擅自新增页面。保留设备重启返回 Launcher 的兼容策略，未经确认不要刷机、提交或发布。

只检查，不修改

请使用 $ai-passport-cover-arts-launcher 检查这个玩法能否接入仅封面页生效的 Up Long 返回协议。不要修改文件；列出封面状态、输入分发点、分区假设和仍需确认的真机项目。

面向玩家的文案
